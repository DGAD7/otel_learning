
### Pre-requisites

Go 1.25 or newer is required (see `ui/go.mod`).
```
brew install go
go version
```
On other platforms, download the installer from https://go.dev/dl/.

#### Tools
```
go install github.com/air-verse/air@latest
```

### How to run the UI
* To the UI navigate to `UI/` folder and run `air` . Alternatively execute `go run`
* More about Golang in this [link](https://go.dev/)
